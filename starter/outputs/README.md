# Generated output directories

These synthetic educational artifacts demonstrate the workflow's filing, audit, and efficiency contracts. They are not submitted to FinCEN and are not legal advice.

## `filed_sars/`

Human-approved SAR JSON documents containing the subject, accounts, transaction summary, Risk Analyst output, Compliance Officer narrative and citations, both named human decisions, UTC metadata, disclaimer, and audit-log location.

## `audit_logs/`

Append-only JSONL records for agent actions, failures and fallbacks, workflow transitions, human decisions, processing time, confidence, regulatory flags, and generated files. `summary.json` is derived from the authoritative JSONL history.

## `metrics/`

Workflow counts, average stage timings, compliance calls avoided by the risk gate, and explicit educational staged-versus-unstaged cost estimates.
